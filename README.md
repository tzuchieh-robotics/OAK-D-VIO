# OAK-D-VIO
VIO project using OAK-D camera.

### System environment
This project is running in WSL on Windows, making it not able to access usb devices directly. With proper setting of 'usbipd' on Windows and 'usbutils' in WSL, programs inside WSL can then interact with usb devices on Windows' usb ports.
